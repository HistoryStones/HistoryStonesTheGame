# History Stones — каркас Ren'Py

Минимальная визуальная новелла на стандартном Ren'Py 8.5.3. Дополнительные
библиотеки не нужны. Интерфейс — стандартный шаблон Ren'Py на русском языке,
1280 × 720; шрифт DejaVu Sans поставляется с движком.

## Запуск

1. Скачайте и распакуйте [Ren'Py SDK](https://www.renpy.org/latest.html).
2. В настройках Ren'Py Launcher укажите каталог проектов `C:\dev`.
3. Выберите `HistoryStonesTheGame` и нажмите «Запустить проект».
4. В главном меню нажмите «Начать».

Можно запустить проект из PowerShell командой из каталога SDK:

```powershell
.\lib\py3-windows-x86_64\python.exe renpy.py C:\dev\HistoryStonesTheGame run
```

В рабочей папке, где создавался каркас, SDK также доступен в
`.tools/renpy-8.5.3-sdk/` (не включён в Git). Из корня проекта:

```powershell
Push-Location .tools/renpy-8.5.3-sdk
try {
    .\lib\py3-windows-x86_64\python.exe renpy.py C:\dev\HistoryStonesTheGame run
} finally {
    Pop-Location
}
```

## Структура и созданные файлы

```text
HistoryStonesTheGame/
├── game/
│   ├── script.rpy             # label start: вызов пролога и выход в меню
│   ├── chapters/
│   │   └── prologue.rpy       # тестовая глава: пять реплик, label prologue
│   ├── options.rpy            # название, версия, сохранения, параметры движка
│   ├── gui.rpy                # стандартные размеры, цвета, шрифты и стили GUI
│   ├── screens.rpy            # штатные экраны меню, диалога, сохранения и настроек
│   └── gui/                   # стандартные PNG-ресурсы интерфейса Ren'Py
├── .gitignore                 # SDK, кэш, сохранения и результаты сборки
└── README.md                  # запуск и описание структуры
```

Все перечисленные файлы созданы в рамках каркаса. Существующий `LICENSE` не
изменялся. Файлы `gui.rpy`, `screens.rpy` и ресурсы `game/gui/` получены из
стандартного шаблона SDK; игровой графики и аудио пока нет.

Ren'Py автоматически читает `.rpy` во вложенных папках `game/`: подключать
главы вручную не требуется. `start` вызывает `prologue` через `call`; первый
`return` завершает главу, второй завершает игру и возвращает в главное меню.
Для новых глав добавляйте файлы в `game/chapters/` с уникальными метками.

## Стандартные функции

- Enter, пробел или щелчок — следующая реплика.
- Esc или правая кнопка мыши — игровое меню.
- Сохранение и загрузка — через меню или кнопки быстрого доступа.
- Настройки — режим экрана, скорость текста, автопереход, пропуск и громкость.
- История реплик, откат, быстрые и автоматические сохранения оставлены штатными.

Постоянный каталог сохранений задан как `HistoryStonesTheGame`; в Windows
пользовательские данные находятся в `%APPDATA%\RenPy\HistoryStonesTheGame`.
Кэш, скомпилированные `.rpyc` и локальные сохранения создаются движком и
исключены из Git.

## Проверка

Каркас проверен на Ren'Py 8.5.3: Lint прошёл без ошибок. На временной копии
проекта выполнена проверка запуска из меню, сохранения и загрузки реплики,
изменения скорости текста, возврата в главное меню и повторного старта
(12 успешных проверок). Скриншоты пролога и настроек также проверены.
Служебная копия проверки находится в `.tools/` и не включена в проект.

Из каталога SDK:

```powershell
.\lib\py3-windows-x86_64\python.exe renpy.py C:\dev\HistoryStonesTheGame lint --error-code
```
