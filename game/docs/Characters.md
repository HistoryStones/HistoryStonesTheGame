#  ПЁТР

 # Наши дни


· Внешность: темноволосый, карие глаза, 25 лет

· Рост: 175 см

· Причёска: длинные волосы, собранные в пучок

· Одежда: красная шапка с помпоном, кожаная 
куртка с мехом, коричневые утеплённые брюки, ботинки Timberland


# Эпоха Викингов


· Одежда:Серая туника-рубаха
· Штаны-брокеры
· Плащ с фибулой
· Кожаная обувь
· Пояс и украшения
· Шлем (во время путешествий)

· Причёска: обратный Малет + борода


# Древняя Греция


· Одежда:Эксомис (короткая рубаха до колен, серая)
· Босиком

· Причёска: короткие растрёпанные волосы до ушей, усы и борода


# Италия (Возрождение)


· Одежда: Комича (рубаха до пояса с манжетами, серая)
· Обтягивающие чулки

· Причёска: ренессансное каре до плеч, небрежная чёлка


# Российская Империя


· Одежда: Белоснежная рубашка + шейный платок
· Плотный кашемировый жилет (бордовый)
· Суконные панталоны
· Закрытые кожаные туфли

· Причёска: волосы зачёсаны влево, бакенбарды


# Лос Алмос:


· Одежда: Белый халат
· Чёрные брюки

· Причёска: волосы зачёсаны назад


# Будущее


· Все вещи из наших дней

# АЛЕКСАНДР

# Наши дни

· Внешность: светловолосый, зелёные глаза, 26 лет
· Рост: 185 см
· Причёска: кудри
· Одежда: без шапки, пуховик, чёрные брюки, ботинки Timberland

# Эпоха Викингов

· Одежда:Меховая куртка
· Серая туника-рубаха
· Штаны-брокеры
· Плащ с фибулой
· Кожаная обувь
· Пояс и украшения
· Шлем (во время путешествий)

· Причёска: длинные волосы до плеч + маленькая косичка у висков

# Древняя Греция

· Одежда: Эксомис (короткая рубаха до колен, серая)
· Босиком

· Причёска: как у Петра, но с повязкой

# Италия (Возрождение)

· Одежда: Комича (рубаха до пояса с манжетами, серая)
· Обтягивающие чулки

· Причёска: вьющиеся волосы

#  Российская Империя

· Одежда: Белоснежная рубашка + шейный платок
· Плотный кашемировый жилет (изумрудный)
· Суконные панталоны
· Закрытые кожаные туфли

· Причёска: волосы зачёсаны вправо

# Лос Алмос:

· Одежда: Белый халат
· Чёрные брюки
· Лабораторные очки

· Причёска: объёмные «шторы»

# Будущее

· Все вещи из наших дней
